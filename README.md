# Chargely

EV charging bay management web application for Amazon EMA2.

## Project

Chargely is a web-based application designed to improve the visibility and management of electric vehicle charging bays.

The application will allow associates to:

- View charging bay availability
- Select an available bay
- Start and manage charging sessions
- Provide estimated charging completion times
- Express interest in a charging bay
- Report incorrect bay or charger status

Facilities users will be able to:

- Monitor charging bay status
- Manage reported issues
- Set bays as out of service
- Review incident history
